# BazarDor (বাজার দর)

## Short Description

BazarDor is a Bengali market price tracking website that helps users check current prices and price changes for everyday products. Product prices are displayed in Bangla, with units such as kilogram, liter, dozen, and piece.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Icons
- DaisyUI
- External product and price API

## Key Features

1. **Product price listings** — View current prices for a range of everyday products.
2. **Bangla interface** — See product names, prices, and units in Bengali.
3. **Price change indicators** — Quickly identify whether a product’s price has increased, decreased, or stayed the same.
4. **Category browsing** — Find products by category, with a not-found page for invalid categories.
5. **Scrolling price ticker** — See product prices and changes in a continuously scrolling marquee.
6. **SignIn and SignUp** — Sign in and Sign up with email, google and github.
7. **Update Profile** — User can update his profie info.
